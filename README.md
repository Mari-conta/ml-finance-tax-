# 📊 ML Finance & Tax | Asesoría Financiera y Tributaria

Plataforma web profesional e interactiva desarrollada como proyecto final para el programa **Jóvenes creaTIvos** (2026). La aplicación brinda asesoría contable, proyecciones fiscales adaptadas a la normativa colombiana actual e integra asistentes virtuales basados en Inteligencia Artificial.

---

## 🚀 Características Principales

* **Indicadores Financieros en Tiempo Real:** Barra superior con métricas clave como UVT 2026 ($52.374) y SMLMV ($1.750.905).
* **Catálogo Interactivo de Servicios:** Modales informativos emergentes con conexión directa a atención personalizada vía WhatsApp.
* **Asistente IA Contable:** Chatbot flotante capacitado para resolver consultas tributarias y contables comunes.
* **Panel de Administración Interno:** Módulo restringido con autenticación para gestión interna de solicitudes de clientes.
* **Diseño 100% Responsive:** Interfaz optimizada para computadores, tabletas y dispositivos móviles.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructura semántica del sitio web.
* **CSS3:** Diseños, maquetación adaptativa (Flexbox/Grid), animaciones y modales.
* **JavaScript (ES6):** Lógica interactiva, control del Chatbot IA y gestión del Panel Admin.
